# 筑家手记用户使用指南

适用版本：0.9.11，电脑与手机浏览器。

## 第一次使用

打开注册页，填写昵称、邮箱和至少 10 位密码，同意隐私说明后注册。无需收取邮箱验证码。注册成功后自动登录，选择创建家庭或打开家人分享的邀请链接。

家庭是共享数据的范围。一个账号可以加入多个家庭，一个家庭可以有多个装修项目，同一家庭内的项目对其全部有效成员可见。

## 建立装修项目

家庭所有者或管理员创建项目，选择半包或全包，再选择常规施工、局部翻新、标准全包或空白流程。填写预算和预计工期，创建后可以调整阶段名称、预算与顺序。

全包项目可填写合同金额，自动分配给“装修公司施工”阶段。半包通常按施工工序记录材料和费用。阶段预算未填写或为零时表示未设置，不显示预算百分比预警。

阶段允许同时进行，例如水电收尾与泥瓦准备可同时标记为进行中。浏览首页阶段不会修改其他家人的施工状态。

## 邀请家人

进入家庭管理，选择成员、只读成员或管理员，生成邀请链接后自行分享。每条链接 48 小时有效、单次使用，可以撤销。家人注册或登录后，先查看家庭名和角色，再确认加入。

| 角色     | 可以做什么                                            |
| -------- | ----------------------------------------------------- |
| 所有者   | 全部操作，任免管理员、转让所有权、永久删除与解散家庭  |
| 管理员   | 设置项目和预算，管理阶段结构，邀请和管理普通/只读成员 |
| 成员     | 共同维护材料、支出和备忘，更新施工状态                |
| 只读成员 | 查看家庭项目和记录，无法修改                          |

成员可编辑家人的共享业务记录，系统保留操作者动态。被移除后不能继续访问，之前记录的支出仍留在家庭账本中。所有者要退出家庭，必须先转让所有权。

## 材料计划与记账

在材料清单记录想买的材料、型号、数量、供应商、计划总金额和采购状态。材料计划是预计费用，不直接计入实际成本。

付款时点“记一笔”，或从材料卡片点“记录付款”。同一个材料可以分别记定金、尾款。记账时选择所属阶段、金额、分类、日期和支付状态，也可以填写商家、支付方式和备注。

“待支付”会计入已记总成本。例如总预算 20 万，材料计划 6 万，已付 3 万，待付 2 万，则总成本为 5 万、预算余额为 15 万。不能把 6 万材料计划再加进总成本。

手机底部中间按钮用于记账。可以复制上一笔，或开启“保存后继续记”；未提交的新支出会保存为当前设备、当前账号和项目的本地草稿。关闭浏览器不是退出账号，退出登录会清理该账号的本机记账草稿。

## 查询、修改和删除

账本支持关键词、阶段、费用分类、支付状态和日期范围筛选，筛选汇总覆盖全部匹配记录。页面每页 30 条，不只统计当前一页。

打开记录可修改。家人已修改同一条记录时，提交会提示版本冲突并保留你的输入；先查看最新内容，再决定如何重新填写。

材料、支出和备忘采用软删除，可以在提示中立即撤销，也能从对应页面的“最近删除”恢复。删除材料不会删除历史支出，不会让已记总成本自动减少。变更材料所属阶段会同步移动其关联支出。

## 装修备忘

备忘按事前确认、设计需求点、灵感与想法等专栏组织。点击标题查看详情，修改内容使用查看弹窗中的“编辑”按钮。编辑描述时回车只是换行，需要另起一条要点时点“新增要点”；描述里的 `http://`、`https://` 网址可以直接点击打开。每条需求可以写多条要点、标重点、切换待确认与已确认，或移动到另一个专栏。

粘贴导入时每行一项，行首 `*` 或星标表示重点，括号内按逗号、顿号等拆分为具体描述。先检查预览，再确认导入；每批最多 100 项，每个项目最多 1000 条有效需求。

## 归档、安全与设备

装修结束后归档项目，仍可查看统计，恢复后继续编辑。永久删除只允许所有者对已归档项目操作，需要输入完整名称和登录密码。解散家庭会删除该家庭的全部项目与记录，应先备份。

“我的账号”中可以修改昵称、管理家庭和项目、退出登录，并查看应用版本。当前版本不提供自助找回密码，忘记密码请联系部署管理员。

浏览器环境允许时，手机可将网页添加到主屏幕。断网时不能提交，只有本机草稿可保留；安装到主屏幕不代表离线写入已支持。家人修改通常会在窗口重新打开或前台刷新周期内更新。

## 备忘文件导入导出（0.9.6）

在“装修备忘 → 导入 / 导出”中导出整个项目或当前专栏，选择 JSON 文件预览后追加导入。同名专栏合并，完全重复内容跳过，不覆盖已有记录。导出不受筛选和分页影响；文件可在 0.9.6 小程序与 Web 之间交换，详见 [备忘文件交换](notes-transfer.md)。
